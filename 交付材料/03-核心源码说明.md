# AI 信息小屋核心源码说明

## 1 代码规模

按排除 `.venv`、`node_modules`、`dist`、缓存和数据目录后的统计口径，仓库共有约 68,441 行源码与测试文本。其中：

- Python 核心业务代码：27,585 行，104 个文件。
- 主 React 前端代码：13,134 行，45 个文件。
- 兼容前端代码：1,299 行，13 个文件。
- Python 测试代码：12,286 行，59 个文件。
- PowerShell 启动脚本：157 行，2 个文件。

## 2 Agent 关键源码

| 文件 | 职责 |
|---|---|
| `backend/src/wechat_agent/agent/graph.py` | System Prompt、LangGraph 状态、决策节点、工具执行节点、条件边和最终状态。 |
| `backend/src/wechat_agent/agent/model.py` | OpenAI 兼容模型调用、原生 function calling、token 统计、服务商异常分类。 |
| `backend/src/wechat_agent/agent/tools.py` | 本地资讯搜索、补充来源、证据构建、授权刷新及参数校验。 |
| `backend/src/wechat_agent/agent/integrations/aihot.py` | AIHOT 独立发现工具，可单独关闭或移除。 |
| `backend/src/wechat_agent/api/agent.py` | Agent 状态、单次运行、会话消息和运行记录 API。 |
| `backend/src/wechat_agent/agent/config.py` | 最大步骤、最大工具调用、超时、输出 token、AIHOT 开关。 |

## 3 完整工程入口

- 本地启动：根目录 `start.ps1`。
- Python 包配置：`backend/pyproject.toml`。
- 兼容依赖清单：根目录 `requirements.txt`。
- 容器构建：根目录 `Dockerfile`。
- 环境变量示例：根目录 `.env.example`。
- 测试入口：在 `backend` 目录执行 `python -m pytest -q`。

## 4 运行限制

Agent 当前采用同步执行和单运行锁。同一时刻只允许一个 Agent 任务，运行记录和会话各保留最近 100 份，且只存于当前进程。SQLite 持久化用于文章、任务、日报、证据和创作内容，但 Agent 会话还没有持久化到 SQLite。
