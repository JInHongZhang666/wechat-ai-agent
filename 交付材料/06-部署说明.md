# AI 信息小屋部署说明

## 1 本地启动

环境要求：Windows 10 或 11、Python 3.12 及以上。视频转写需要 FFmpeg；如果使用独立 Speaches 服务，还需要 Docker Desktop。

```powershell
cd "D:\Program Files\Obsidian\.worktrees\wechat-ai-agent-core(1)\05_PROJECTS\wechat-ai-agent"
Copy-Item .env.example .env
# 编辑 .env，填写自己的模型 Key
.\start.ps1
```

启动后访问：

- 主页面：`http://127.0.0.1:8010/`
- 灵犀探讯：`http://127.0.0.1:8010/agent`
- API 文档：`http://127.0.0.1:8010/docs`
- Agent 状态：`http://127.0.0.1:8010/api/v1/agent/status`

停止服务时在启动终端按 `Ctrl+C`。

## 2 手动安装

```powershell
cd backend
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e ".[agent,dev]"
$env:WECHAT_AGENT_DATABASE_URL = "sqlite:///./data/wechat_agent.db"
$env:WECHAT_AGENT_AGENT_ENABLED = "1"
.\.venv\Scripts\python.exe -m uvicorn wechat_agent.main:app --app-dir src --host 127.0.0.1 --port 8010 --workers 1
```

## 3 Docker 部署

```powershell
docker build -t ai-cabin-agent .
docker run --rm -p 8010:8010 `
  --env-file .env `
  -v "${PWD}\data:/app/data" `
  ai-cabin-agent
```

容器必须保持一个 Uvicorn worker，因为当前 Agent 会话、运行记录、调度器和部分内存状态以单进程方式管理。SQLite 数据通过 `/app/data` 卷持久化。

## 4 环境变量

| 变量 | 用途 | 默认或示例 |
|---|---|---|
| `WECHAT_AGENT_LLM_API_KEY` | OpenAI 兼容模型密钥 | 必填，写入本机 `.env` |
| `WECHAT_AGENT_LLM_BASE_URL` | 模型接口地址 | `https://api.deepseek.com/v1` |
| `WECHAT_AGENT_LLM_MODEL` | 内容创作和默认 Agent 模型 | `deepseek-chat` |
| `WECHAT_AGENT_AGENT_MODEL` | 单独覆盖 Agent 模型 | 未设置时沿用上项 |
| `WECHAT_AGENT_AGENT_ENABLED` | Agent 开关 | `1` |
| `WECHAT_AGENT_AIHOT_ENABLED` | AIHOT 独立扩展开关 | `1` |
| `WECHAT_AGENT_AGENT_MAX_STEPS` | 最大决策步数 | `6` |
| `WECHAT_AGENT_AGENT_MAX_TOOL_CALLS` | 最大工具调用数 | `8` |
| `WECHAT_AGENT_AGENT_TIMEOUT_SECONDS` | 单次运行超时 | `120` |
| `WECHAT_AGENT_DATABASE_URL` | SQLite 或 Mongo 持久化地址 | 启动脚本默认本地 SQLite |

不要提交真实 `.env`。仓库只提交 `.env.example`。

## 5 视频转写服务

```powershell
# GPU 自动选择
.\start-video.ps1

# 强制 CPU
.\start-video.ps1 -Cpu

# 停止
.\start-video.ps1 -Stop
```

视频转写服务独立放在 `services/video-transcriber`。它可以单独启动和移除，不影响资讯 Agent 的核心运行。

## 6 健康检查

```powershell
Invoke-WebRequest http://127.0.0.1:8010/ -UseBasicParsing
Invoke-RestMethod http://127.0.0.1:8010/api/v1/agent/status
```

期望结果：主页 HTTP 200；Agent 状态中 `enabled=true`、`model_configured=true`，工具列表包含本地研究工具，AIHOT 开启时还包含 `search_aihot_news`。

## 7 常见故障

| 现象 | 原因 | 处理方法 |
|---|---|---|
| `AGENT_DISABLED` | Agent 开关关闭 | 设置 `WECHAT_AGENT_AGENT_ENABLED=1` 后重启 |
| `AGENT_MODEL_NOT_CONFIGURED` | 没有读取到模型密钥 | 检查 `.env` 是否位于项目根目录，变量名是否正确 |
| `AGENT_BUSY` | 已有同步任务执行 | 等当前任务完成后重试 |
| AIHOT 无结果 | 上游限频、网络或条件过窄 | 缩短关键词、改为 7 天，或关闭 AIHOT 使用本地库 |
| 会话重启后消失 | 当前会话是进程内存存储 | 后续版本可把会话迁移到 SQLite |
| Docker 中数据丢失 | 未挂载 `/app/data` | 使用卷映射持久化数据目录 |
